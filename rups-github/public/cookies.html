Cookie Policy

Cookies, browser storage and related technologies on the Rups website, including your controls.

Last updated: 16 October 2026

Scope and contact

This policy describes the current Rups website and administrator sign-in. Rups is operated from Montenegro, with correspondence address Gavra Vukovića bb, 81000 Podgorica, Montenegro. For questions about browser storage or privacy, contact privacy@rups.io.

The separate online clinic software is still under development. Its storage technologies will need to be documented before launch; this website inventory does not certify or describe a completed SaaS configuration. Read this alongside the Privacy Policy.

Cookies and similar technologies

Cookies are small values a website asks a browser to store and return with later requests. They can support a sign-in session, preferences, measurement or advertising. First-party cookies relate to the site you visit; third-party technologies may involve another provider.

Local storage, session storage and tracking pixels are different technologies that can also store or communicate information. Ordinary browser caching stores assets such as images and scripts to help a page load; it is not the same as an advertising identifier.

The essential administrator cookie

Name: __Host-rups_admin. Provider: this Rups website. Purpose: keeping an authorised administrator signed in. Duration: up to eight hours from session creation. Category: essential authentication.

The cookie contains a random session identifier, not the administrator’s plain-text password or a copy of demo submissions. A corresponding hashed identifier is used on the server to check the session. The cookie has Secure, HttpOnly and SameSite=Strict attributes and is restricted to the site host and root path.

This cookie is set when an administrator successfully sets up access or signs in. Successful sign-out invalidates that session and clears the cookie. Blocking or removing it prevents continued authenticated access. It is not used for advertising or cross-site audience tracking.

Public browsing and demo forms

The website’s own public-page code does not currently set analytics, advertising or preference cookies. It does not include tracking pixels or store demo form details in local storage or session storage.

Demo verification does store information on the server and sends an email. Server-side storage is different from a browser cookie and is covered by the Privacy Policy. Closing the browser or clearing cookies does not delete a confirmed demo enquiry from the database.

Embedded clinic videos are served as website media files rather than third-party video-player embeds. Social icons are ordinary links, not embedded social feeds. Following an Instagram, X or YouTube link takes you to that provider, whose own storage practices and choices then apply.

Hosting, security and external services

Vercel hosts the current website. Supabase supports server-side database storage and Resend delivers verification emails. A provider’s involvement in the backend does not, by itself, mean that it places an advertising cookie in your browser.

Hosting or security infrastructure may process request information independently of the website’s own cookie code. A provider-operated dashboard or access-protected preview can also have its own authentication technologies. This policy does not claim that every external service uses no cookies.

For provider practices, consult Vercel’s privacy information and the provider links in our Privacy Policy. We will need to update this inventory if the public site enables additional storage technologies.

Your browser controls

You can inspect, delete or block cookies and site data through your browser’s privacy settings. Controls vary by browser and device. You can also sign out of the administrator area to end that session.

Blocking the administrator cookie will affect sign-in. Public browsing and demo submission do not depend on that administrator cookie. Clearing browser data does not cancel an enquiry, erase server records or withdraw permissions previously given to a separate service.

To request access to or deletion of information held by Rups, use privacy@rups.io, rather than relying on browser-cookie deletion.

Optional technologies and future changes

There are currently no optional analytics or advertising categories enabled by the website’s own code, so this site does not present a selector for those categories. This does not mean that optional tracking could be introduced without notice or, where required, prior consent.

Before introducing optional technologies, their purpose, provider, duration and available controls must be disclosed and any legally required consent obtained. Where consent is used, withdrawal must be available. Future SaaS authentication, preferences or measurement will need its own verified inventory.

The date above identifies the current version of this policy. Material changes to storage practices will require an appropriate update and any further choices required by applicable law.
